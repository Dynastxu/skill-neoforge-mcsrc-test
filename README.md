# skill-neoforge-mcsrc-test

This is a test repo for [skill-neoforge-minecraft-sources](https://github.com/Dynastxu/skill-neoforge-minecraft-sources) and [skill-external-lib-sources](https://github.com/Dynastxu/skill-external-lib-sources).

## Run Tests

### Requirements

- PowerShell 7.0 or higher
- Pester

### Commands

```powershell
Invoke-Pester .\test\mcsrc.Tests.ps1
Invoke-Pester .\test\libsrc.Tests.ps1
```
